# Chronicles of the Ethereal Ruins — Official Website & Documentation

The public marketing website, App Store privacy policy, support station, and project documentation for **Chronicles of the Ethereal Ruins** (《灵墟纪》), an offline-first minimalist Eastern ink cultivation simulator for iOS and Web.

Published at:
<https://liuyang1520.github.io/chronicles-of-the-ethereal-ruins-site/>

## Pages

- `/` — Product overview, lore, features, screenshots, and 6-language localization showcase
- `/privacy/` — Official App Store & Web privacy policy (zero-tracking, offline-first)
- `/support/` — Cultivator support desk, FAQ, and issue submission
- `/docs/bgm.md` — AI music generation prompt plan across all scenes and realms

Feedback and support requests are accepted at:
<https://github.com/liuyang1520/chronicles-of-the-ethereal-ruins-site/issues/new>

## Localization

Chronicles of the Ethereal Ruins supports 6 major languages:
1. **English**: Chronicles of the Ethereal Ruins
2. **Simplified Chinese (简体中文)**: 灵墟纪
3. **Traditional Chinese (繁體中文)**: 靈墟紀
4. **Japanese (日本語)**: 霊墟紀 (れいきょき)
5. **Korean (한국어)**: 영허기
6. **Spanish (Español)**: Crónicas de las Ruinas Etéreas

## Architecture

The website is crafted with semantic HTML5 and vanilla CSS. It requires zero build steps, external JavaScript runtime dependencies, or analytics trackers, guaranteeing instant page loads and complete privacy.

Commits to `main` deploy automatically to GitHub Pages via `.github/workflows/pages.yml`.
